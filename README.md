# DroneManagementSystem

DroneManagementSystem is a SQL Server database project for managing drone fleet operations. It includes a schema script for accounts, pilots, drones, stations, accessories, and related operational records.

## Features

- Normalized SQL Server schema for drone fleet management
- Tables for assets, operators, accounts, addresses, and station assignments

## Tech Stack

- Microsoft SQL Server
- T-SQL

## Getting Started

Run the schema script from SQL Server Management Studio or Azure Data Studio:

```text
DroneManagementSystem(schema).sql
```

## Project Structure

- `DroneManagementSystem(schema).sql`: database schema
